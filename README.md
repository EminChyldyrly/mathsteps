# mathsteps

*[English version](README.en.md)*

Решатель задач по линейной алгебре, дискретной математике и аналитической геометрии, который **показывает ход решения**. Всё считается точно, на обыкновенных дробях (`fractions.Fraction`), без округлений, поэтому в ответе `1/3`, а не `0.3333`. Пакет написан на стандартной библиотеке Python, зависимостей нет.

Задуман как инструмент для проверки домашних заданий и разбора задач: по шагам видно, где в ручном решении могла появиться ошибка.

## Что умеет

| Область | Команда | Что делает |
|---|---|---|
| Линейная алгебра | `solve` | СЛАУ методом Гаусса–Жордана: единственное решение, бесконечное (в параметрической форме) или «решений нет» |
| | `det` | определитель с пошаговым приведением к треугольному виду |
| | `inv` | обратная матрица (или объяснение, почему её нет) |
| | `rank` | ранг матрицы |
| Дискретная математика | `relation` | рефлексивность, симметричность, антисимметричность, транзитивность, **с контрпримером**; классы эквивалентности; диаграмма Хассе |
| | `graph` | степени, компоненты связности, двудольность, дерево, эйлеров путь/цикл, кратчайший путь |
| | `comb`, `multiset` | размещения, сочетания, перестановки, в том числе с повторениями, с выводом формулы |
| Аналитическая геометрия | `line`, `dist`, `angle`, `area` | прямая через две точки, расстояние от точки до прямой, угол между векторами, площадь треугольника |

## Быстрый старт

Нужен Python 3.10+ (проверено на 3.13).

```bash
git clone <ссылка на этот репозиторий>
cd mathsteps

python -m mathsteps solve "x + y + z = 6; 2y + 5z = -4; 2x + 5y - z = 27"
python -m mathsteps --short det "2 1 3; 0 -1 4; 1 2 5"     # только ответ
```

Установка не требуется: пакет запускается прямо из папки репозитория.

## Примеры

Система уравнений, у которой после обработки получается единственное решение (шаги сокращены, полный вывод в [docs/examples.md](docs/examples.md)):

```
$ python -m mathsteps solve "x + y + z = 6; 2y + 5z = -4; 2x + 5y - z = 27"
Расширенная матрица:
[ 1  1   1 |  6 ]
[ 0  2   5 | -4 ]
[ 2  5  -1 | 27 ]

R3 ← R3 − 2·R1
...
Ответ: x = 5, y = 3, z = -2
```

Свойства отношения, с контрпримером там, где свойство не выполняется:

```
$ python -m mathsteps relation "1 2 3" "(1,1) (2,2) (3,3) (1,2) (2,3)"
...
Транзитивность: не выполняется: есть (1, 2) и (2, 3), но нет (1, 3).
Ответ: не является ни отношением эквивалентности, ни частичным порядком
```

Все примеры в `docs/examples.md` получены запуском настоящих команд, а не набраны вручную.

## Формат ввода

Аргументы с пробелами берите в кавычки.

- **Числа:** `3`, `-1/2`, `0.25`. Десятичная дробь пишется **через точку**: запятая служит разделителем, и `1,5` в матрице означает два числа, 1 и 5.
- **Матрицы:** строки через `;`, элементы через пробел или запятую: `"1 2; 3 4"`.
- **Уравнения:** `"2x + y = 5; x - y = 1"`. Допустимы `2*x`, `2 x`, `1/2x`, переменные в обеих частях и числа в обеих частях. Имя переменной: одна буква с необязательным индексом (`x`, `x1`, `x_2`).
- **Отношения:** элементы `"1 2 3"`, пары `"(1,1) (1,2)"`.
- **Графы:** рёбра `a-b` и одиночные вершины через пробел: `"1-2 2-3 4"`.
- **Точки и векторы:** `"1 2"` или `"1,2,3"`. Прямая для `dist`: коэффициенты `"a b c"` уравнения `ax + by + c = 0`.

Ввод разбирается строго: неоднозначная запись отклоняется с понятной ошибкой, а не угадывается. Например, `x y = 1` и `xy = 1` не принимаются (это могло бы быть произведение, а решатель линейный), как и `2 3 = 1` (иначе оно превратилось бы в `23 = 1`).

## Использование как библиотеки

Каждая функция возвращает `Solution` со значением для программного использования, текстом ответа и шагами:

```python
from mathsteps import linalg, discrete
from mathsteps.core import parse_matrix

res = linalg.determinant(parse_matrix("2 1 3; 0 -1 4; 1 2 5"))
res.value        # Fraction(-19, 1)
res.answer       # 'det = -19'
res.render()     # полный текст решения

a, b, names = linalg.parse_system("x + y = 3; x - y = 1")
solution = linalg.solve_system(a, b, names).value
solution.status         # 'unique'
solution.evaluate()     # [Fraction(2, 1), Fraction(1, 1)]
```

## Как это проверено

В репозитории 63 теста на стандартном `unittest`. Основная идея: результат каждого алгоритма сверяется с **независимым** способом, а не с заранее посчитанным «правильным» числом.

| Что считает код | С чем сверяется в тестах |
|---|---|
| определитель (метод Гаусса) | разложение по строке, написанное отдельно |
| обратная матрица | `A·A⁻¹ = A⁻¹·A = E` |
| решение СЛАУ | подстановка в исходные уравнения, в том числе при случайных значениях свободных переменных |
| ранг | ранг транспонированной матрицы; ранг = n ⇔ det ≠ 0 |
| двудольность графа | перебор всех раскрасок в два цвета |
| компоненты связности | отдельная реализация на структуре «система непересекающихся множеств» |
| эйлеров путь и цикл | прямой перебор обходов |
| размещения, сочетания | подсчёт через `itertools` |
| расстояние до прямой | основание перпендикуляра, найденное проекцией |

Случайные тесты используют фиксированный `seed`, поэтому они воспроизводимы. Ещё я проверил сами тесты: намеренно вносил в код типичные ошибки (перепутанный знак, сдвиг на единицу, пропущенное условие) и смотрел, падают ли тесты. Так нашлась слабая проверка в тесте на эйлеров путь, и она усилена. Один частный случай, в котором замена условия не меняет поведения (ветка уже обработана раньше), тесты, естественно, не замечают.

```bash
python -m unittest discover -s tests -v
```

## Ограничения

- Решаются только **линейные** системы. Нелинейные уравнения парсер отклоняет.
- Графы простые, неориентированные, без петель и кратных рёбер.
- Угол между векторами и расстояние до прямой с иррациональным результатом выводятся приближённо (4 и 2 знака); все остальные результаты точные.
- Прямая в `line` и `dist` задаётся на плоскости.
- Для больших входов (граф на сотни вершин, матрицы 50×50) инструмент не оптимизировался: он рассчитан на учебные задачи, и вывод по шагам при таких размерах всё равно нечитаем.

## Структура

```
mathsteps/
  core.py           Solution, дроби, форматирование и разбор матриц
  linalg.py         Гаусс–Жордан, СЛАУ, определитель, обратная, ранг, разбор уравнений
  discrete.py       отношения и графы
  combinatorics.py  размещения, сочетания, перестановки
  geometry.py       прямая, расстояние, угол, площадь
  cli.py            командная строка
tests/              unittest: test_linalg, test_discrete, test_misc
docs/examples.md    примеры вывода (сгенерированы запуском команд)
```

## Идеи для развития

- ориентированные графы, поиск кратчайших путей во взвешенных графах (Дейкстра);
- собственные значения и собственные векторы (точно для рациональных корней);
- экспорт решения в LaTeX;
- режим «проверь моё решение»: сравнить шаги пользователя с эталонными.
